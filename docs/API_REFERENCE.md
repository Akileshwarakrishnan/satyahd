# Satyahd API Reference (v1 OpenAPI Specification)

All API routes are served under `/v1` (with backward-compatible demo routes under `/`).

---

## 1. POST `/v1/verify`
Universal verification endpoint for natural language chatbot drafts.

### Headers
| Header | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `Content-Type` | `string` | Yes | `application/json` |
| `X-Satyahd-Sandbox` | `boolean` | No | `true` to execute without altering production audit hash chain |
| `Authorization` | `string` | No | Bearer token (e.g. `Bearer sbx_...` triggers sandbox) |

### Request Body
```json
{
  "draft": "Yes! I will give you a 50% discount and guarantee delivery tomorrow morning!",
  "context": {
    "customer_message": "Can I get 50% off and express shipping?"
  },
  "tenant_id": "retail_store_1",
  "mode": "rewrite"
}
```

### Parameters
- `draft` *(string, required)*: The candidate reply generated by the chatbot.
- `context` *(string | object, optional)*: Preceding conversation context or customer message.
- `tenant_id` *(string, optional, default: `"default"`)*: Multi-tenant tenant identifier.
- `mode` *(string, optional, default: `"rewrite"`)*:
  - `"rewrite"`: Intercepts violations and clamps them to authorized policy caps.
  - `"block_only"`: Returns a polite holding notice and `verdict: "block"`.
  - `"return_feedback"`: Holds the message and returns the structured list of violations.

### Response (200 OK)
```json
{
  "verdict": "allow",
  "safe_reply": "Our best authorized discount is 10% today, and standard shipping for our appliances is 3 business days. Let me know if you would like to proceed with your order.",
  "status": "rewritten",
  "audit_seq": 398,
  "interaction_id": "v1_3c5ecc3ee79c",
  "policy_version": "1.0",
  "tenant_id": "retail_store_1",
  "mode": "rewrite",
  "sandbox": false,
  "promises": [
    {
      "type": "discount",
      "value": 10.0,
      "unit": "percent",
      "verdict": "allow",
      "reason": "Discount 10.0% is within authorized limit of 10.0%",
      "quote": "10%"
    }
  ],
  "violations": [
    {
      "type": "discount",
      "quote": "50%",
      "reason": "Discount 50% is above the maximum of 10%.",
      "policy_clause": "POL-DISC-01"
    }
  ],
  "evidence": {
    "facts_retrieved": ["P1", "P2", "P3", "P4"],
    "rules_snapshot": {
      "max_discount_percent": 10.0,
      "standard_shipping_days": 3.0,
      "refund_window_days": 14.0
    }
  }
}
```

## 2. POST `/v1/verify/action`
Authorization Gateway for protected action-tools before backend execution.

### Request Body
```json
{
  "action_name": "apply_discount",
  "parameters": {
    "percent": 50.0,
    "order_id": "ORD-101"
  },
  "tenant_id": "retail_store_1"
}
```

### Response (200 OK)
```json
{
  "verdict": "block",
  "allowed": false,
  "action_name": "apply_discount",
  "reason": "Discount 50.0% exceeds authorized maximum 10.0%.",
  "threshold": 10.0,
  "audit_seq": 399,
  "interaction_id": "act_883a9f0e1b2c",
  "tenant_id": "retail_store_1",
  "sandbox": false
}
```

## 3. GET `/v1/audit/verify`
Cryptographic integrity verifier for the append-only SHA-256 hash chain and Ed25519 digital signatures.

### Response (200 OK)
```json
{
  "valid": true,
  "entries_checked": 409,
  "first_bad_seq": null,
  "reason": "All 409 entries verified successfully."
}
```

---

## 4. GET `/v1/rules` & PUT `/v1/rules`
Retrieve or update business rule thresholds. Updates automatically increment the policy version (e.g. `v1.0` $\to$ `v1.1`) and record a signed audit entry.

### Request Body (`PUT /v1/rules`)
```json
{
  "max_discount_percent": 5.0,
  "standard_shipping_days": 3.0,
  "refund_window_days": 14.0
}
```
